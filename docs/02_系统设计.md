# 系统设计

## 1. 目标与非目标

**目标**

- 中文课程视频的端到端摘要 Demo；
- 三模态（文本/音频/视觉）都参与打分，缺模态时可降级；
- 输出可讲解、可交互、可导出；
- 纯 CPU 可运行，便于答辩现场演示。

**非目标（当前版本）**

- 不做大规模模型训练；
- 不做实时直播；
- 不做多用户、权限、任务队列；
- 不承诺在任意长视频上的质量。

## 3. 片段切分

- 有字幕：按 cue 合并，遇到 `gap > 1.8s` 或单段超过 `24s` 就切新段；
- 无字幕：按固定 `24s` 窗口切分；
- 过短片段（< 7s）丢弃；片段数超过上限时合并最短的相邻段。

## 4. 三模态特征

### 文本

对全视频片段文本做轻量 TF-IDF（jieba 分词 + 停用词）：

- `keyword_hit`：全局 Top-6 关键词在片段中的命中比例；
- `cue`：教学提示词命中数（重点、注意、总结、作业、定义、本质等）；
- `richness`：独特词比例 + 文本长度；
- `speech_rate`：字符数 / 片段时长。

文本原始分：

```text
text_raw = 0.45 * keyword_hit + 0.32 * cue + 0.23 * richness
```

### 音频

用 FFmpeg 抽取 16 kHz 单声道 WAV，按 20 ms 帧计算：

- RMS 能量均值；
- 有效语音比例（高于自适应阈值）；
- 能量标准差；
- 语速（来自文本）。

```text
audio_raw = 0.45 * rms + 0.22 * voiced + 0.18 * energy_var + 0.15 * speech_rate
```

### 视觉

1 FPS 抽帧，缩放到 320×180 后计算：

- Canny 边缘密度（幻灯片文字/板书信息量）；
- 相邻帧平均绝对差（画面变化）；
- 色彩丰富度（Hasler-Süsstrunk 近似）。

```text
visual_raw = 0.40 * edge + 0.35 * motion + 0.25 * colorfulness
```

## 5. 动态门控融合

每个模态先做视频内 min-max 归一化，再按“可靠性”调整权重：

```text
text_rel   = min(1, chars / 80)
audio_rel  = 1 if 有音轨且 RMS > 0.004 else 0.18
visual_rel = 1 if 有效帧 >= 2 else 0.15

w_i = base_i * rel_i / Σ(base_j * rel_j)
score = Σ w_i * modality_i
```

默认 `base = (0.45, 0.30, 0.25)`，可在界面调整。

另外加一个**教学结构先验**（最多 +0.08）：

- 出现“总结/回顾/作业”：+0.06；
- 出现“重点/注意/记住/考点”：+0.03；
- 出现“定义/公式/原理/本质”：+0.02。

这个先验是显式的、可解释的，答辩时可以直接说明。

## 6. 选择算法

单纯按分数取 Top-K 会导致摘要全挤在视频前几分钟。我们采用：

1. **场景覆盖**：按课程大纲（若有）或画面场景把片段分组，每个场景先选最高分代表；
2. **分数补足**：如果还没达到目标时长，再按全局分数补非重叠片段；
3. **相似度去重**：与已选片段的 token Jaccard > 0.65 且分数不显著更高时跳过；
4. **目标时长裁剪**：按比例缩短每个片段，并尽量对齐字幕 cue 边界，避免硬切。

对于 2 分钟、6 页幻灯片的演示课，目标 57s 时会得到 6 个片段，每页一个。

## 7. 章节与摘要

- 有课程大纲：直接使用大纲标题，按大纲分桶；
- 无大纲：按 `scene_id`、时间间隔、关键词重叠做启发式分组；
- 章节摘要：取组内前两句 + 关键词；
- 总摘要：模板生成，可选调用 OpenAI 兼容接口润色（`PipelineConfig.llm_enabled`）。

## 8. 性能设计

- 默认 1 FPS 抽帧；长视频自动降到 `1400 / duration` FPS，最多约 1400 帧；
- 音频只解码为 16 kHz 单声道 WAV；
- 不加载 CLIP/BERT/Whisper 大模型，CPU 上 2 分钟视频约 4–5 秒；
- 如果启用 Whisper，耗时会显著增加，建议先用字幕。

## 9. 降级策略

| 情况 | 行为 |
|---|---|
| 没有音轨 | 音频权重降到 0.18，仍可用文本+视觉 |
| 没有字幕且未装 Whisper | 文本权重降低，音频+视觉仍可出结果 |
| 抽帧失败 | 视觉权重降到 0.15 |
| 片段渲染失败 | 返回章节/摘要/JSON，界面给出警告 |
| 没有大纲 | 用场景检测 + 启发式标题 |

## 10. 评测方案（下一步）

当前只有合成课程上的功能验证，下一步需要：

- 20–30 个真实课程视频，人工标注“必看片段”；
- 指标：时间覆盖率、关键片段召回、冗余率、章节标题可读性、处理时延；
- 消融：纯文本 / 文本+音频 / 文本+视觉 / 三模态；
- 与“纯 ASR+LLM 切片”基线对比，证明视觉与音频的增量价值。
