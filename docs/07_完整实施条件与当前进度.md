# 完整实施条件与当前进度

## 1. 当前结论

项目已经具备可运行的 CPU 教育视频摘要闭环，但原始申报书中的完整目标还包含
深度多模态训练、跨行业语义理解、Jetson 端侧部署和真实数据评测。以下条件不是
代码里可以自动补齐的，需要数据、算力或硬件。

当前环境已经满足：

- Python 3.11 便携运行环境；
- FFmpeg、OpenCV、NumPy、Pillow、scikit-learn；
- faster-whisper small 本地模型；
- RapidOCR；
- 可选 VLM 画面语义后端与证据缓存代码；
- Word COM，可用于验证生成的 DOCX；
- 纯 CPU 端到端处理。

## 2. 本轮已经补齐

- 教育、安防、社交、会议共 22 个内置关键词模板；
- 自定义关键词和用户模板保存；
- 模板先验参与片段排序，并保留命中依据；
- 时间分层场景选择，避免摘要集中在视频前半段；
- 裁剪后的目标时长二次补足，控制摘要时长误差；
- 最多 8 个默认章节，可配置 3–12 个；
- 代表帧质量评分，惩罚闪切、转场和高饱和伪影；
- MP4 / MOV / AVI 输出；
- 480P / 720P / 1080P 输出高度选择；
- TXT、DOCX、关键帧 PDF 导出；
- 关键词主题子摘要；
- 保留/删除反馈记录 `feedback.json`；
- 时间覆盖率、主题召回、严格主题召回、精确率、内容冗余和时长误差评测；
- 通用重要片段标注评测入口。

## 3. 需要用户提供或确认

### 3.1 真实数据

正式评测至少需要：

- EDUVSUM 官方包：98 个教育视频、15 个官方测试视频，约 2.58 GB；
- 或 20–30 个有授权的本校中文课程录像；
- 每个中文视频建议提供 5–10 个人工标注的重要片段和课程大纲；
- 安防和社交媒体场景各至少 10–20 个视频及事件时间标注。

当前网络访问 Zenodo 实测约 150 KB/s，下载完整 EDUVSUM 需要数小时。
更合适的方式是提供已经下载好的数据目录，或在高速网络环境下载。

EDUVSUM 地址：<https://zenodo.org/records/4002959>

### 3.2 深度模型训练环境

原要求中的 CLIP/BERT/YOLO/LSTM 训练建议至少准备：

- NVIDIA GPU，显存 12 GB 起步，推荐 24 GB；
- CUDA 12.x 与匹配的 PyTorch；
- 20–50 GB 可用磁盘用于模型、特征和缓存；
- 如训练 Temporal/Transformer 模型，建议 24 GB 以上显存。

CPU 可以运行轻量特征原型，但不适合完整微调原计划中的 BERT、YOLO、CLIP 和
时序模型。没有这些条件时，继续使用当前的三路手工特征作为可运行基线。

视觉语义推理不等同于模型训练：当前已支持 2B–4B 级预训练 VLM 在 8 GB 显存上
做量化推理。正式启用前仍需确认并下载 PyTorch/Transformers 依赖和模型权重。

### 3.3 端侧部署环境

原计划中的 30 FPS 和 8 GB 显存指标必须用真实设备复测：

- Jetson Orin Nano 8 GB，安装 JetPack、CUDA、TensorRT；
- 或至少一台具有独立 NVIDIA GPU 的笔记本；
- 需要记录端到端处理倍率、峰值内存、功耗和单帧推理 FPS，不能混用指标。

### 3.4 章节标题和总摘要润色

当前模板式标题可以保证不编造，但可读性有限。要达到产品级标题，建议提供：

- 一个 OpenAI 兼容接口或校内 LLM 服务；
- 或本地 Qwen / GLM 模型及至少 8–16 GB 显存。

没有 LLM 时保留当前抽取式标题和摘要回退。

### 3.5 存储

本项目处理长视频时会同时生成音频、抽帧、片段和预览。完整数据、模型和输出建议：

- 系统盘至少保留 20 GB；
- 数据盘至少保留 100 GB；
- 1 小时视频建议使用独立输出目录，并定期清理旧结果。

## 4. 正式评测步骤

1. 将单个视频跑成 `result.json`。
2. 准备标注 JSON：

```json
{
  "important_segments": [
    {"start": 120, "end": 185, "label": "知识点名称"},
    {"start": 310, "end": 360, "label": "实验步骤"}
  ]
}
```

3. 执行：

```powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONPATH = (Get-Location).Path
.\runtime\python311\python.exe .\scripts\dev\evaluate_result.py `
  .\outputs\<result-dir>\result.json `
  .\data\benchmarks\<video>.gt.json
```

4. 批量报告至少包含：

- 目标时长误差；
- 主题召回；
- 严格主题召回；
- 片段精确率；
- 标注区间覆盖率；
- 内容冗余率；
- 章节数；
- 处理耗时、实时倍率和峰值内存；
- 纯文本 / 文本+音频 / 三模态消融。

## 5. 不能把临时指标写进结题报告

当前 `education_early_computing` 临时标注用于工程回归，可以证明流程和选择逻辑
改善，不等于 EDUVSUM 官方成绩。正式报告必须用官方标注或独立双人标注，
并保留评测脚本、输入清单和运行日志。
