# 灵影速览 · 项目一页纸

## 项目名称

灵影速览——基于多模态大模型的智能视频摘要生成系统

## 一句话

让中文课程视频自动变成“可跳转的章节 + 值得看的片段 + 可复习的关键帧”，
而不只是一段文字总结。

## 痛点

- 一节 45–90 分钟课程，复习时只能反复拖进度条；
- 现有工具大多只处理语音/字幕，PPT、板书、实验演示等画面信息被忽略；
- 通用摘要工具输出固定，不能按章节、关键词、时长定制。

## 方案

输入课程视频，输出：

1. 带时间戳的章节与摘要；
2. 按目标时长挑选的重点片段（MP4）；
3. 关键帧拼图与摘要字幕（SRT）；
4. 可交互的 Web 界面：保留/删除片段、关键词检索、重新渲染。

技术链路：

```text
字幕/ASR → 片段切分 → 文本+音频+视觉特征 → 动态门控融合
→ 场景覆盖选择 → 章节/摘要 → 片段/关键帧/时间轴导出
```

## 创新点

1. **三模态可靠门控**：文本、音频、视觉各自打分，缺模态自动降权；
2. **教学结构先验**：重点、注意、总结、作业等教学提示词参与评分；
3. **场景/大纲覆盖**：每个章节/幻灯片先选代表片段，避免摘要全挤在开头；
4. **轻量可离线**：纯 CPU 可跑，不依赖 GPU 或云端 API；
5. **人机协同**：机器初筛 + 人工增删 + 反馈闭环。

## Demo 实测（合成课程，非真实课堂）

| 指标 | 数值 |
|---|---|
| 原视频 | 2 分 08 秒 |
| 摘要 | 52 秒（41%） |
| 章节 | 6 个（每页幻灯片 1 个） |
| 处理耗时 | 4.6 秒（CPU） |
| 实时倍率 | 约 28× |

## 与竞品/开源的差异

- 开源切片工具多为“ASR + LLM 打分 + FFmpeg 剪辑”，视觉不参与决策；
- 多模态摘要研究（EDUVSUM/MMSum）多停留在论文与离线特征，缺少可用产品；
- NVIDIA VSS 能力强，但依赖 GPU/NIM，部署成本高；
- 我们的定位是**中文教育场景、纯 CPU、可离线、可交互的轻量方案**。
