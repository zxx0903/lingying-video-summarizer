## 3. 长视频吞吐基准

为测试长视频效率，把已验证的 11 分 53 秒课程无损重复 5 次，形成
3563.35 秒（59 分 23 秒）测试视频，并同步偏移中文字幕。

| 项目 | 结果 |
|---|---:|
| 原视频 | 3563.35 秒 |
| 目标摘要 | 300 秒 |
| 实际摘要 | 300.00 秒 |
| 处理耗时 | 188.58 秒 |
| 墙钟耗时 | 189.36 秒 |
| 实时倍率 | 约 18.8 倍 |
| 自适应抽帧 | 0.393 FPS，1400 帧 |
| 输出片段 | 20 |
| 章节 | 12 |

这满足原计划“1 小时视频 5 分钟内完成”的 CPU 基线。测试内容是重复课程，
因此只能用于吞吐、时长和稳定性验证，不能代表一小时课程的知识覆盖质量。

首轮内存采样中，项目 Python 进程峰值工作集约 0.26 GB；GPU 未使用。该数值
不是操作系统全部进程的硬件总峰值，正式报告应继续用性能计数器补测。

基准输出目录：

```text
D:\lingying_test_data\benchmark\output_v3
```
