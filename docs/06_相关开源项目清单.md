## 结论

- “视频摘要”不缺开源项目，缺的是**中文教育场景 + 多模态融合 + 轻量部署 + 交互闭环**的组合。
- 我们的 Demo 站在 OpenClip/EDUVSUM/MMSum 的肩膀上，但核心评分、选择、交互和演示数据是新写的。
